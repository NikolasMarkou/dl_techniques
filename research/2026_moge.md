## 1. What MoGe is (from the pasted code)

Single-image metric geometry: point map + depth + mask + (V2/V3) normal + metric scale + intrinsics/FOV, one forward pass. All versions share the inference contract `infer(image (B,3,H,W) float [0,1]) -> {points (B,H,W,3) OpenCV x-right/y-down/z-forward, depth (B,H,W), intrinsics (B,3,3) normalized, mask (B,H,W) bool, normal (B,H,W,3)?}` with `num_tokens` / `resolution_level 0..9`, `fov_x?`, `apply_mask`, `force_projection` (recompute points from depth+intrinsics).

| Ver | File | Encoder | Neck / head | Outputs | Params (README) |
|---|---|---|---|---|---|
| V1 | `moge/model/v1.py` | vendored DINOv2 (`modules/dinov2/`: `hub/backbones.py dinov2_vits14/vitb14/vitl14/vitg14(+_reg)`, `models/vision_transformer.py DinoVisionTransformer`, `layers/{attention,block,mlp,swiglu_ffn,layerscale,drop_path,patch_embed}`) via `get_intermediate_layers`, `Head` in-file | `Head`: 1x1 `projects` per feature -> sum, 3x `ConvTranspose2d+Conv2d` upsample + `ResidualConvBlock` (GroupNorm1+ReLU+Conv3x3, replicate pad), UV concat (`normalized_view_plane_uv`) at every stage, final 1x1/3x3 to `[3,1]` (points+mask) | affine-invariant points, mask; depth+intrinsics derived in `infer()` | 314M (vitl) |
| V2 | `moge/model/v2.py` | `modules/dinov2_encoder.py DINOv2Encoder` (normalize, resize to `token_rows*14`, `output_projections` 1x1 sum) | `modules/conv_stack.py ConvStack` as shared `neck` + `points_head/mask_head/normal_head` + `modules/mlp.py MLP scale_head` on CLS token | metric points (`exp` remap), normal (L2-norm), mask (sigmoid), `metric_scale` (exp) | 35M (vits) / 104M (vitb) / 326-331M (vitl) |
| V3 | `moge/model/v3.py` extends V2 | same as V2 | + `modules/sparse_unet.py Sparse3DUNet` refiner on `(x/z,y/z,logz)` voxels, `refiner_depth_resolution=256`, `refine_steps=3`, `refiner_detach_backbone_until` | V2 outputs + `points_per_step/depth_per_step/intrinsics_per_step`, per-step focal/shift recovery | 370M (vitl) / 1.25B (vitg) |

Common machinery (must be ported or replaced, none is in `dl_techniques` today):
`_remap_points {linear,sinh,exp,sinh_exp}`, `recover_focal_shift` (`utils/geometry_torch.py` -> `geometry_numpy.py solve_optimal_focal_shift/solve_optimal_shift` via scipy `least_squares`, 64x64 downsample), `normalized_view_plane_uv`, `mask_aware_nearest_resize`, `wrap_module_with_gradient_checkpointing/autocast`, `import_model_class_by_version`, `from_pretrained` from HF `model.pt` (`model_config`+`model`, `strict=False` with missing-key warn), `init_weights` from torch.hub DINOv2, `enable_gradient_checkpointing/mixed_precision`, `onnx_compatible_mode` flag.
Losses (`train/losses.py`): `affine_invariant_global_loss` (low-res `align_points_scale_z_shift`, optional `fixed_scale` pin for refine steps), `affine_invariant_local_loss` (anchor sampling + `align_points_scale_xyz_shift`, needs preceding global scale), `radial_partition_local_loss[_rand_partition]` (+`RadialPartitionLocalLossCache`, `radial_partition`, `segment_align_shift`), `normal_loss` (cross-product angle), `edge_loss`, `normal_map_loss` (squared angle), `mask_l2/bce`, `metric_scale_loss/l1` (log-space), `shift_invariant/decoupled/l1_global`, `normal_map_tv`. Alignment core (`utils/alignment.py`): truncated-L1 `align`, `align_depth_{scale,affine}`, `align_points_{scale,scale_z_shift,scale_xyz_shift,z_shift,xyz_shift}`, `align_depth_shift_with_scale` (Gauss-Newton), `segment_robust_weighted_median`.
Data (`train/dataloader.py`, `utils/data_augmentation.py`): perspective sample/warp, reject-and-resample on warped-valid ratio, edge-aware depth warp (bilinear in disparity + nearest), flip, color jitter/dof/shot/blur/jpeg, `metric_from_meta` / `depth_unit` / `finite_depth_mask` knobs.
Eval (`test/metrics.py`, `test/dataloader.py`, `test/baseline.py MGEBaselineInterface`): metric groups `global/metric/local`, suites `moge2/moge3`, boundary-F1, per-segment local with global-scale + per-segment shift.

## 3. Ready-made reuse inventory (factory-first, §9.1)

Do NOT write bespoke layers for these; wire factories/existing layers.

**Encoder (biggest win — do not vend a third ViT).**
* `models/vision/dino/dino_v2.py` — already a Keras DINOv2 with registers, LayerScale (`constraint='non_neg'` divergence noted), iBOT mask input, SwiGLU giant variant, `get_intermediate_layers`-equivalent outputs (`x_norm_clstoken/regtokens/patchtokens`). Reuse as `DINOv2Encoder` backbone; add only the 1x1 `output_projections` sum + ImageNet normalize. Check `dino/common.py`, `reference_init.py` for init conventions.
* Fallback/composition: `layers/transformers/vision_encoder.py VisionEncoder` (factory-routed patch embed / attention / FFN / norm, CLS+pos embed, `PatchEmbedType linear/siglip/conv/hybrid`) + `layers/transformers/transformer.py TransformerLayer`. Prefer `VisionEncoder` over raw `models/vision/vit/model.py ViT` for the new package — `ViT` defaults `normalization_position='post'` vs published pre-LN (documented divergence D-047); DINOv2 needs pre-norm.
* Factories: `layers/attention/factory.py create_attention_layer` (35 types; need plain global MHA for dinov2 blocks), `layers/ffn/factory.py create_ffn_layer` (22 types incl. `swiglu` for vit-g, `mlp`/`geglu`; watch `swiglu.hidden_dim` derivation rule §9.5 + `assemble_ffn_config`), `layers/norms/factory.py create_normalization_layer` (19 types; factory epsilon 1e-6 vs Keras 1e-3 — construct DINOv2 norms via factory or pass explicit `epsilon=` with citation), `layers/embedding/factory.py create_embedding_layer` (`patch_2d`, `positional_learned`, registers via `embedding/register_tokens.py`, mask via `mask_token.py`, class token via `class_token.py`), `layers/regularization/layer_scale.py LayerScale` + `stochastic_depth.py StochasticDepth` + `utils/drop_path.py linear_drop_path_rates`, `layers/activations/common.py resolve/serialize_activation` trio.

**Neck / dense heads (V1 Head, V2 ConvStack).**
* Closest existing: `models/vision/depth_anything/components.py DPTDecoder` (conv-bn-act stages, power-of-2 `upsample_factor`, linear output for affine losses, `REFERENCE_BN_EPSILON=1e-5`) — reuse or subclass for `points/normal/mask` heads; `models/vision/omnipoint/heads.py RayDistanceHead/MaskHead/MetricScaleHead` shows the exact pattern (one DPTDecoder + `geometric/ray_point_combinator.RayPointCombinator` for unit-ray/positive-distance/point split; mask linear logits for BCE-from-logits; scale head as small MLP on pooled token because DPT preserves spatial axes).
* Primitives: `layers/conv_blocks/{conv_block,basic_block,bottleneck_block,convnext_v1_block,depthwise_separable_block}.py` for residual blocks (MoGe `ResidualConvBlock` ≈ ConvBlock + skip; check first), `layers/pooling/{pixel_shuffle,pixel_unshuffle,blur_pool,patch_merging}.py` for `Resampler` modes, `layers/heads/vision/factory.py create_vision_head(DEPTH_ESTIMATION)` / `DepthEstimationHead` for the depth-projection tail, `layers/dense_block.py DenseBlock` / `residual_dense_block.py` + `layers/ffn/mlp.py MLPBlock` for the CLS `scale_head` (MoGe `MLP` = Linear+ReLU stack + Linear; factory `mlp` key owns the bare name).
* UV-aspect conditioning: no factory; implement as `keras.ops`-only concat (like `normalized_view_plane_uv`), keep shapes in one pure helper used by `build/call/compute_output_shape` (§3.4).

**FOV/conditioning analogues.**
* `utils/camera_models.py` (`pinhole_ray_map/unproject`, fisheye, equirect) + `layers/geometric/sparse_depth_splat.py` + `models/vision/omnipoint/conditioning.py ConditioningInputEncoder/ConditioningStateEmbedding` = the house pattern for optional intrinsics/sparse-depth conditioning and present/absent flags. MoGe `fov_x` input maps onto this; keep conditioning create-always/use-conditionally (§1.3) with explicit names.
* `utils/homography.py` (data-pipeline only, raw TF allowed — never in `call()`), `layers/spatial_layer.py` (CoordConv grid + bilinear sample, graph-safe).

**Losses — extend, don't duplicate.**
* `losses/affine_invariant_loss.py AffineInvariantLoss` (median/MAD normalize, per-sample `(batch,)` return — the shape rule; all new losses return `(batch,)`, never scalar) covers V1-global conceptually; MoGe global needs the least-squares `scale+z_shift` alignment variant → new `MogeGlobalLoss` reusing `_masked_mean_over_all_but_batch` pattern from `losses/omnipoint_losses.py`.
* `losses/omnipoint_losses.py` is the template: `RayDirectionLoss`, `PointDistanceLoss` (GT-ray projection decoupling + externally-computed `s*` via `compute_optimal_scale`, stop-gradient on target), `MetricScaleLoss` (log-space), `MaskLoss` (BCE from logits), `NormalConsistencyLoss`/`LocalConsistencyLoss` (finite-difference cross-product + discrete Laplacian — documented D-004 simplification; MoGe `normal_loss/edge_loss` map here), `OmniPointCombinedLoss` callable (tuple-output wiring precedent for `compile`). Add `MogeLocalLoss` (patch/radial variants), `MogeMaskLoss`, `MogeNormalLoss` in the same file shape, registered `@register_dl_technique("dl_techniques.losses.<module>")`, Google-or-Sphinx matched to file.
* Invariants to pin: per-sample shape predicate (`weighted == unweighted*mean(w)` + the `w=[1,..,0]` batch-term arm for scale-coupled terms), finite outputs (`ops.all(isfinite)`), fp16 sentinel derived from `compute_dtype` (`ops.where` not `(1-mask)*-1e9`), never-narrow float32 guard.

**Utils / training.**

## 4. MoGe→Keras port notes (defects to avoid by construction)

* Build contract (§8): `__init__` creates all sublayers with explicit `name=`; `build()` materializes exactly what `call()` runs (conditional heads built conditionally + anti-vacuity `head=None builds no head weights` test); `explicit-build == lazy-build` parity test on relative weight paths; `load_own_variables` dummy-forward for nested ViT/DPT submodels (copy `depth_anything/model.py:942-962`); weight-value identity test `atol=0.0` before first call on reloaded model.
* Graph safety (§4): no `scipy.optimize`, no `.numpy()`, no Python-`if`-on-tensor in `call()` — `recover_focal_shift` least-squares stays in numpy post-processing / trainer / application, not in the forward path. No `ops.tril/triu`; route `training=` explicitly through every norm/dropout; causal-mask style N/A but masked-row map for invalid depth must be `ops.where`-based.
* Numerics (§10): patch-grid reductions assert finite; empty-mask path returns finite (masked-mean epsilon pattern); mixed_float16 + float64 construction-and-forward tests for every masked/reduction layer; epsilon audit on every norm (factory 1e-6 vs reference).
* Config (§6): every ctor arg in `get_config` (incl. `remap_output`, `num_tokens_range`, `refiner_depth_resolution`, `refine_steps`); `from_config` deserializes nested encoder/head objects; new `ValueError`s get `from_config` substitute+warn migration path; caches only pure functions of shape/dtype.

## 5. The V3 refiner decision (load-bearing)

`Sparse3DUNet` rides `flex_gemm` Triton `SubmanifoldConv3d/SparsePool3d/SparseUpsample3d` + `NeighborCache` reuse across down/up passes. No equivalent in `layers/` (`geometric/` has autoencoder/supernode, `graphs/` has GCN/transformer — none is submanifold sparse conv). macOS unsupported upstream. Options: (A) ship `moge` with V1+V2 + V3-architecture with `refine_steps=0` path and `refiner=None` warn (mirrors upstream ctor), refiner as follow-up — recommended; (B) dense 3D-UNet approximation (changes numerics, must be named as non-faithful like `mobile_clip_v1`); (C) custom sparse op (out of scope for first pass). Either way V3 `forward(return_per_step)` becomes tuple/dict output without Python-list appends in `call()` (unroll fixed max steps or `ops.scan`).
